1679C - Rocks Defenders

You have a square chessboard of size n×n. Rows are numbered from top to bottom with numbers from 1 to n, and columns — from left to right with numbers from 1 to n. So, each cell is denoted with pair of integers (x,y) ( 1≤x,y≤n), where x is a row number and y is a column number.

You have to perform q queries of three types:

  • Put a new rook in cell (x,y).

  • Remove a rook from cell (x,y). It's guaranteed that the rook was put in this cell before.

  • Check if each cell of subrectangle (x1,y1)−(x2,y2) of the board is attacked by at least one rook.

Subrectangle is a set of cells (x,y) such that for each cell two conditions are satisfied: x1≤x≤x2 and y1≤y≤y2.

Recall that cell (a,b) is attacked by a rook placed in cell (c,d) if either a=c or b=d. In particular, the cell containing a rook is attacked by this rook.

Input

The first line contains two integers n and q ( 1≤n≤105, 1≤q≤2⋅105) — the size of the chessboard and the number of queries, respectively.

Each of the following q lines contains description of a query. Description begins with integer t ( t∈{1,2,3}) which denotes type of a query:

  • If t=1, two integers x and y follows ( 1≤x,y≤n) — coordinated of the cell where the new rook should be put in. It's guaranteed that there is no rook in the cell (x,y) at the moment of the given query.

  • If t=2, two integers x and y follows ( 1≤x,y≤n) — coordinates of the cell to remove a rook from. It's guaranteed that there is a rook in the cell (x,y) at the moment of the given query.

  • If t=3, four integers x1,y1,x2 and y2 follows ( 1≤x1≤x2≤n, 1≤y1≤y2≤n) — subrectangle to check if each cell of it is attacked by at least one rook.

It's guaranteed that among q queries there is at least one query of the third type.

Output

Print the answer for each query of the third type in a separate line. Print "Yes" (without quotes) if each cell of the subrectangle is attacked by at least one rook.

Otherwise print "No" (without quotes).

我觉得 ds 的题主要是看出什么量值得维护且可以维护，它对时间复杂度起到什么作用。

最朴素的想法就是对于每个放置和删除车的操作，都遍历一下对应的行和列去挨个标记点，对于询问就暴力从 (x1,y1) 搜到 (x2,y2) ，看下是不是每个点都被标记了。

但是车标记的特性是一次操作一行/列，所以真的有必要细化到点吗？如果列 x1→x2 都被标记了或者行 y1→y2 都被标记了，不就等于说全部点都被标记了？因此，我们分别维护 c[x] 和 r[y] 表示列 x 和行 y 是否被标记（0/1值）。原问题变成单点修改区间查询问题，最简单就是写两个树状数组，当然写线段树也没毛。

xxxxxxxxxx
#include<bits/stdc++.h>
#define lowbit(x) x&-x
using namespace std;
struct BIT{
    int n;
    vector<int> a;
    BIT(int n):n(n),a(n+1,0){}
    
    void add(int x,int v){
        for(;x<=n;x+=lowbit(x))a[x]+=v;
    }
    int query(int x){
        int res=0;
        for(;x;x-=lowbit(x))res+=a[x];
        return res;
    }
    int query(int l,int r){
        return query(r)-query(l-1);
    }
};
int main(){
    int n,q;
    cin>>n>>q;
    /*query的主体是(x1,y1)->(x2,y2)是否全部都被攻击了
    不妨分开思考，只要所有行/所有列都被攻击就行
    否则必然有一个交点没被攻击
    因此用两个树状数组分别维护 c,l 的攻击情况
    */
    vector<int> r(n+1,0),c(n+1,0);
    BIT tr(n),tc(n);
    while(q--){
        int t;
        cin>>t;
        if(t==1){
            int x,y;
            cin>>x>>y;
            ++r[x];
            if(r[x]==1)tr.add(x,1);
            ++c[y];
            if(c[y]==1)tc.add(y,1);
        }
        else if(t==2){
            int x,y;
            cin>>x>>y;
            --r[x];
            if(r[x]==0)tr.add(x,-1);
            --c[y];
            if(c[y]==0)tc.add(y,-1);
        }
        else{
            int x1,y1,x2,y2;
            cin>>x1>>y1>>x2>>y2;
            if(tr.query(x1,x2)==x2-x1+1 || tc.query(y1,y2)==y2-y1+1)cout<<"Yes\n";
            else cout<<"No\n";
        }
    }
    return 0;
}

1791F - Range Update Point Query

Given an array a1,a2,…,an, you need to handle a total of q updates and queries of two types:

  • 1 l r — for each index i with l≤i≤r, update the value of ai to the sum of the digits of ai.

  • 2 x — output ax.

Input

The first line of the input contains an integer t ( 1≤t≤1000) — the number of testcases.

The first line of each test case contains two integers n and q ( 1≤n,q≤2⋅105) — the size of the array and the number of queries, respectively.

The second line of each test case contains n integers a1,a2,…,an ( 1≤ai≤109).

The next q lines of each test case are of two forms:

  • 1 l r ( 1≤l≤r≤n) — it means, for each index i with l≤i≤r, you should update the value of ai to the sum of its digits.

  • 2 x ( 1≤x≤n) — it means you should output ax.

There is at least one query of the second type.

The sum of n over all test cases does not exceed 2⋅105.

The sum of q over all test cases does not exceed 2⋅105.

Output

For each test case, output the answers of queries of the second type, in the order they are given.

这题也是一样的，观察到数字更新为自身数位之和，不出三步必然变成个位数。所以如何避免冗余的遍历和更新？维护区间最大值，对于区间最大值已经剩个位数的了肯定不用管了；剩下的挨个更新。本来是 O(n)，这样就变成 O(log⁡n) 了。

所以这是一个区间修改单点查询的问题，上线段树。

xxxxxxxxxx
#include<bits/stdc++.h>
#define ls(x) x<<1
#define rs(x) x<<1|1
using namespace std;
const int N=2e5+10;
//由于数位不超过 9，其实应该维护区间最大值，而且随着更新最后一定是->个位数
//所以不超过9 的直接跳了
int calc(int x){
    int res=0;
    while(x){
        res+=x%10;
        x/=10;
    }return res;
}
int tr[N<<2|1],a[N];
void build(int x,int l,int r){
    if(l==r){
        tr[x]=a[l];
        return ;
    }
    int mid=l+r>>1;
    build(ls(x),l,mid);
    build(rs(x),mid+1,r);
    tr[x]=max(tr[ls(x)],tr[rs(x)]);
}
void modify(int x,int l,int r,int ql,int qr){
    if(tr[x]<=9)return ;
    if(l==r){
        tr[x]=calc(tr[x]);
        return ;
    }int mid=l+r>>1;
    if(ql<=mid)modify(ls(x),l,mid,ql,qr);
    if(qr>mid)modify(rs(x),mid+1,r,ql,qr);
    tr[x]=max(tr[ls(x)],tr[rs(x)]);
}
int query(int x,int l,int r,int p){
    if(l==r)return tr[x];
    int mid=l+r>>1;
    if(p<=mid)return query(ls(x),l,mid,p);
    else return query(rs(x),mid+1,r,p);
}
void solve(){
    int n,q;
    cin>>n>>q;
    for(int i=1;i<=n;i++)cin>>a[i];
    build(1,1,n);
    while(q--){
        int t;
        cin>>t;
        if(t==1){
            int l,r;
            cin>>l>>r;
            modify(1,1,n,l,r);
        }else{
            int x;
            cin>>x;
            cout<<query(1,1,n,x)<<"\n";
        }
        
    }
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    
    return 0;
}

1294D - MEX maximizing

Recall that MEX of an array is a minimum non-negative integer that does not belong to the array. Examples:

  • for the array [0,0,1,0,2] MEX equals to 3 because numbers 0,1 and 2 are presented in the array and 3 is the minimum non-negative integer not presented in the array;

  • for the array [1,2,3,4] MEX equals to 0 because 0 is the minimum non-negative integer not presented in the array;

  • for the array [0,1,4,3] MEX equals to 2 because 2 is the minimum non-negative integer not presented in the array.

You are given an empty array a=[] (in other words, a zero-length array). You are also given a positive integer x.

You are also given q queries. The j-th query consists of one integer yj and means that you have to append one element yj to the array. The array length increases by 1 after a query.

In one move, you can choose any index i and set ai:=ai+x or ai:=ai−x (i.e. increase or decrease any element of the array by x). The only restriction is that ai cannot become negative. Since initially the array is empty, you can perform moves only after the first query.

You have to maximize the MEX (minimum excluded) of the array if you can perform any number of such operations (you can even perform the operation multiple times with one element).

You have to find the answer after each of q queries (i.e. the j-th answer corresponds to the array of length j).

Operations are discarded before each query. I.e. the array a after the j-th query equals to [y1,y2,…,yj].

Input

The first line of the input contains two integers q,x ( 1≤q,x≤4⋅105) — the number of queries and the value of x.

The next q lines describe queries. The j-th query consists of one integer yj ( 0≤yj≤109) and means that you have to append one element yj to the array.

Output

Print the answer to the initial problem after each query — for the query j print the maximum value of MEX after first j queries. Note that queries are dependent (the array changes after each query) but operations are independent between queries.

操作的不变性在于 a[i]%x。 思考 MEX 取不到更大的瓶颈在哪里？就是小的值还没有被“填满”。对所有 a[i] 按照模 x 的剩余系分类，比如说当前有 cnt[k] 个 k(k∈[0,x−1]) 了，那么仅对于 k 而言它管不到的最小正整数值就是 cnt[k]*x+k 。由于 cnt 差个 1 整个数值必然 ±x，因此显然 cnt 更小的放在前面。

所以维护所有的配对 (cnt[y],y) 的有序集合，根据追加的值动态修改它并取集合里的首个元素作为答案。平衡树我不会手搓，用 set 吧。时间复杂度 O(nlog⁡n)

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
int main(){
    int q,x;
    cin>>q>>x;
    vector<int> mods(x);
    set<pair<int,int>> vals;
    for(int i=0;i<x;i++)vals.insert(make_pair(mods[i],i));
    while(q--){
        int p;
        cin>>p;
        p%=x;
        vals.erase(make_pair(mods[p],p));
        ++mods[p];
        vals.insert(make_pair(mods[p],p));
        cout<<vals.begin()->first * x + vals.begin()->second<<"\n";
    }
    return 0;
}

继续观察还可以发现 mex 对于多个 query 一定是不减的。所以也有线性复杂度的做法：

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
int main(){
    int q,x;
    cin>>q>>x;
    vector<int> cnt(q+1);
    int mex;
    while(q--){
        int y;
        cin>>y;
        ++cnt[y%x];
        while(cnt[mex%x]>0)
            --cnt[mex%x],++mex;
        cout<<mex<<"\n";
    }
    return 0;
}

1454F - Array Partition

You are given an array a consisting of n integers.

Let min(l,r) be the minimum value among al,al+1,…,ar and max(l,r) be the maximum value among al,al+1,…,ar.

Your task is to choose three positive (greater than 0) integers x, y and z such that:

  • x+y+z=n;

  • max(1,x)=min(x+1,x+y)=max(x+y+1,n).

In other words, you have to split the array a into three consecutive non-empty parts that cover the whole array and the maximum in the first part equals the minimum in the second part and equals the maximum in the third part (or determine it is impossible to find such a partition).

Among all such triples (partitions), you can choose any.

You have to answer t independent test cases.

Input

The first line of the input contains one integer t ( 1≤t≤2⋅104) — the number of test cases. Then t test cases follow.

The first line of the test case contains one integer n ( 3≤n≤2⋅105) — the length of a.

The second line of the test case contains n integers a1,a2,…,an ( 1≤ai≤109), where ai is the i-th element of a.

It is guaranteed that the sum of n does not exceed 2⋅105 ( ∑n≤2⋅105).

Output

For each test case, print the answer: NO in the only line if there is no such partition of a that satisfies the conditions from the problem statement. Otherwise, print YES in the first line and three integers x, y and z ( x+y+z=n) in the second line.

If there are several answers, you can print any.

这题看起来可以尝试的方向很多啊，依旧是先抓不变性和半不变性。我们考虑对于左指针 l，随着 l 的递增，第一段的最大值肯定是不减的；考虑右指针 r，随着 r 的递减，第三段的最大值也一定是不减的，且每个 l 一定可以预处理出一个和它匹配的“最远”的 r；而随着这两个指针的运动，中间段的元素数量逐渐减少，其最小值也一定是不减的……而因为这题不涉及对原序列的修改操作，只是要 query 一下区间最值，写个 st 表就行了。

所以，一个想法就是朴素枚举左指针，右指针在 (i+2,r) 上二分查找。由于 st 表 query 是 O(1) 的，总复杂度即为 O(nlog⁡n)。

写 st 表的时候记得位运算优先级问题，一个小疏忽，debug 时候给我整破防了。。。

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
const int N=2e5+10,Lg=20;
/*
判定数组 a 是否能划分成三段，第一段最大值=第二段最小值=第三段最大值
定义左指针 l 和右指针 r，取第一段为 [1,l] 第三段为 [r,n] 第二段为 [l+1,r-1]
随着 l++，第一段最大值是不减的。第二段最小值也是不减的。
考虑对第一段结尾 i 预处理 pre[i]=max(1,i),suf[i]=min(i,n)
那么现在只需要找到 min(i+1,j-1)=pre[i]=suf[j]
另一方面，j 增大时 suf[j] 应该是不增的，所以同一个值应该对应一个连续区间，存一下最左边那个端点。
再利用单调性二分 j 就行了。
*/
int a[N];
int lg[N],st[Lg][N],pre[N],suf[N];
int query(int l,int r){
    int k=lg[r-l+1];
    return min(st[k][l],st[k][r-(1<<k)+1]);
}
int main(){
    int t;
    cin>>t;
    for(int i=2;i<=N;i++)lg[i]=lg[i/2]+1; //循环要到 N
    while(t--){
        int n;
        cin>>n;
        for(int i=1;i<=n;i++){
            cin>>a[i];
            st[0][i]=a[i];
        }
        for(int k=1;(1<<k)<=n;++k){
            for(int i=1;i+(1<<k)-1<=n;++i)
                st[k][i]=min(st[k-1][i],st[k-1][i+(1<<(k-1))]);
        }
        //预处理最小值
        pre[1]=a[1];
        for(int i=2;i<=n;i++)pre[i]=max(pre[i-1],a[i]);
        suf[n]=a[n];
        for(int i=n-1;i>=1;--i)suf[i]=max(suf[i+1],a[i]);
        map<int,pair<int,int> >pos;
        for(int i=1;i<=n;i++){
            if(!pos.count(suf[i]))
                pos[suf[i]]={i,i};
            else
                pos[suf[i]].second=i;
        }
        bool flag=0;
        int x,y,z;
        x=y=z=0;
        for(int i=1;i<=n-2 && !flag;++i){
            int v=pre[i];
            if(!pos.count(v))continue;
            int l=max(i+2,pos[v].first),r=pos[v].second;
            if(l>r)continue;
            int ql=l,qr=r,w=-1;
            while(ql<=qr){
                int mid=ql+qr>>1;
                if(query(i+1,mid-1)<=v){
                    w=mid;
                    qr=mid-1;
                }else ql=mid+1;
            }
            if(w!=-1 && query(i+1,w-1)==v)
                x=i,y=w-i-1,z=n-w+1,flag=1;
        }
        if(!flag)cout<<"NO\n";
        else cout<<"YES\n"<<x<<" "<<y<<" "<<z<<"\n";
    }
    return 0;
}
