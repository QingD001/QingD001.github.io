B - Polyline

There are N points on the xy-plane, numbered 1,2,…,N. The coordinates of point i are (i,Ai).

For i=1,2,…,N−1, connect point i and point i+1 with a line segment to form one polyline.

Find the number of points on this polyline (including its endpoints) whose y-coordinate is K.

Here, the constraints guarantee that the number of points satisfying the condition is finite.

  • 2≤N≤100

  • 1≤Ai≤100 (1≤i≤N)

  • Ai≠Ai+1 (1≤i<N)

  • 1≤K≤100

  • All input values are integers.

对于顶点独立判定，开区间内的自然统计就行。

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,k,res=0;
    cin>>n>>k;
    vector<int> a(n+1);
    for(int i=1;i<=n;i++){
        cin>>a[i];
        if(a[i]==k)++res;
    }
    for(int i=2;i<=n;i++){
        int x1=i-1,x2=i;
        int y1=a[x1],y2=a[x2];
        if(y1>y2)swap(y1,y2);
        if(y1<k && y2>k)++res;
    }
    cout<<res;
    return 0;
}

C - Bank Accounts

In the backyard of Kowasugi Bank, ghosts are growing pumpkins. You have decided to open bank accounts for the pumpkins.

When a bank account for a pumpkin is opened, it is assigned one name and one ID. The ID is chosen as the smallest positive integer that is not yet used as an ID.

Initially, no bank accounts for pumpkins have been opened. The following event occurs Q times; process them in order.

  • A pumpkin comes and introduces itself with the name s.

    • If there is an account assigned the name s, print its ID.

    • If there is no account assigned the name s, open one new account with the name s and print its ID.

  • Q is an integer between 1 and 2×105, inclusive.

  • In each event, s is a string of length between 1 and 10, inclusive, consisting of lowercase English letters.

你需要 O(1) 的查询。

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
int main(){
    int q,cnt=0;
    cin>>q;
    unordered_map<string,int> id;
    while(q--){
        string s;
        cin>>s;
        if(id[s])cout<<id[s]<<"\n";
        else {
            id[s]=++cnt;
            cout<<id[s]<<"\n";  
        }
    }
    return 0;
}

D - Autopilot

There are N planets and M routes. The planets are numbered 1 to N, and the routes are numbered 1 to M.

Route i goes from planet Ai to planet Bi. Each route is one-way.

A spaceship can perform the following two types of operations.

  • Move, without consuming fuel, to the planet with the smallest number among the planets directly reachable by a route from the current planet.

  • Choose any planet directly reachable by a route from the current planet, and move to the chosen planet, consuming 1 unit of fuel.

Find the minimum amount of fuel the spaceship consumes to start from planet S and arrive at planet T. If it is impossible to reach planet T, print −1 instead.

  • 2≤N≤2×105

  • 1≤M≤2×105

  • 1≤S,T≤N

  • S≠T

  • 1≤Ai,Bi≤N

  • Ai≠Bi

  • All input values are integers.

0/1 bfs 板子题

#include<bits/stdc++.h>
using namespace std;
constexpr int inf=0x3f3f3f3f3f;
int main(){
    int n,m,s,t;
    cin>>n>>m>>s>>t;
    vector<vector<int>> g(n+1);
    vector<int> mini(n+1,inf);
    for(int i=1;i<=m;i++){
        int a,b;
        cin>>a>>b;
        g[a].push_back(b);
        mini[a]=min(mini[a],b);
    }
    deque<int> q;
    q.push_front(s);
    vector<int> d(n+1,inf);
    d[s]=0;
    while(!q.empty()){
        int x=q.front();
        q.pop_front();
        for(auto xx:g[x]){
            int w=(xx==mini[x] ? 0:1);
            if(d[xx]>d[x]+w){
                d[xx]=d[x]+w;
                if(w==0)q.push_front(xx);
                else q.push_back(xx);
            }
        }
    }
    if(d[t]!=inf)cout<<d[t];
    else cout<<-1;
    return 0;
}

E - Most Brilliant Starry Sky

There are N stars on the xy-plane. The i-th star is represented as the point with coordinates (Xi,Yi).

Draw one line that passes through the origin and does not pass through any star, and choose one of the two regions into which the line divides the plane.

Find the maximum possible number of stars contained in the chosen region.

You are given T test cases; solve each of them.

  • 1≤T≤2×105

  • 1≤N≤2×105

  • The sum of N over all test cases is at most 2×105.

  • −109≤Xi,Yi≤109

  • (Xi,Yi)≠(0,0)

  • (Xi,Yi)≠(Xj,Yj) (i≠j)

  • No two distinct stars are collinear with the origin.

  • All input values are integers.

直观的思路是，如果当前切分线的斜率确定了，只要比较所有 yi/xi 与斜率的关系，即可统计两个区域的点数。问题在于 xi 可能为 0。顺着这个方向进一步思考，把所有点按照相对于原点的顺序排序好，由于单个区最多涵盖角度差异为 π 的所有点，考虑双指针法构造窗口并计算。

实现上有一些细节，比如整个点列后部的区间还可以扫回来，所以复制一份把环形问题转化成线性问题。这里用叉积的原因是可以避免 atan2l 的精度问题（一开始用 atan2l WA了三发，罚时吃满了）。开 long long 避免叉积的时候爆 int。

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
struct P{
    ll x,y;
};
ll cs(P a,P b){
    return a.x*b.y-a.y*b.x;
}
ll dot(P a,P b){
    return a.x*b.x+a.y*b.y;
}
bool up(P p){
    return p.y>0 || (p.y==0 && p.x>0);
}
bool cmp(P a,P b){
    if(up(a)!=up(b))return up(a);
    return cs(a,b)>0;
}
void solve(){
    int n;
    cin>>n;
    vector<P> p;
    for(int i=1;i<=n;i++){
        ll x,y;
        cin>>x>>y;
        p.push_back({x,y});
    }
    sort(p.begin(),p.end(),cmp);
    for(int i=0;i<n;i++)p.push_back(p[i]);
    int ans=0,r=0;
    for(int l=0;l<n;l++){
        if(r<l)r=l;
        while(r<l+n){
            ll c=cs(p[l],p[r]),d=dot(p[l],p[r]);
            if(c>0 || (c==0 && d>0))++r;
            else break;
        }
        ans=max(ans,r-l);
    }
    cout<<ans<<"\n";
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}

F - Evil Shortest Path

You are given a directed graph with N vertices and M edges. The vertices are numbered 1,2,…,N. The i-th edge goes from vertex Ai to vertex Bi, and a digit Ci between 1 and 9, inclusive, is written on this edge.

When moving along the edges in their directions, the integer obtained by concatenating the digits written on the traversed edges in the order they are traversed is called the score of the movement. For example, if the digits written on the traversed edges are 3,1,4 in this order, the score of the movement is 314. The same vertex or edge may be traversed multiple times.

For each v=2,3,…,N, find the minimum score of a movement from vertex 1 to vertex v, modulo 998244353. Here, it is guaranteed that the given directed graph allows moving from vertex 1 to every other vertex along the edges in their directions.

  • 2≤N≤2×105

  • N−1≤M≤2×105

  • 1≤Ai,Bi≤N

  • 1≤Ci≤9

  • All input values are integers.

  • It is possible to move from vertex 1 to every other vertex along the edges in their directions.

分数的比较规则其实就是字符串的比较规则，先看长度再看字符大小。如果直接 bfs，每一层扩展只能确保长度的有序性（即后入队的状态必然比先入队的状态长度更长），但不确保字典序的有序性。所以我们要对 bfs 进行一个变形，让我们的算法在同一层内部也按照路径的字典序从小到大访问状态。

直观的来看，既然字典序比较优先看首位，就给每个顶点的出边按照数字从小到大排序。可惜这是错的。考虑这样的搜索树：

在数字大小同样的情况下，bfs 不考虑后面的情况，所以从 1 开始搜的话会先访问 2，3，从而得到 19 再得到 12，这就不确保有序性了。只用顶点作状态的话，如果前面的某一层扩展出了问题，后面一定全是错的。而我们要比较路径的整体前缀，再比较下一条边。

既如此，为什么不把相同前缀的顶点，视为同种状态一起扩展呢？比如对于上面这棵树， G1={2,3} 表示所有能够通过得分为 1 的路径1到达的、尚未被更优路径访问过的顶点。这样访问顺序就会变成 G12=4 和 G19=4，这样就对了。具体而言，定义状态 Gk：

Gk={v| Greatest Score(v)=k}

对于这个组的所有出边，按照边权 1-9 的顺序处理。每次弹出组时，把组中所有顶点的出边按照数字分到九个桶里，然后依次生成新组并加入队列。这样的 bfs 必然满足第一次到达已经最优，所以每种状态只会访问一次。时间复杂度 O(N+M)，也是压线通过了。

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int P=998244353;
struct Group{
    vector<int> ver;
    int val;
};
int main(){
    int n,m;
    cin>>n>>m;
    vector<vector<pair<int,int>>> g(n+1);
    for(int i=1;i<=m;i++){
        int u,v,c;
        cin>>u>>v>>c;
        g[u].push_back({v,c});
    }
    vector<int> ans(n+1);
    vector<bool> vis(n+1,false);
    queue<Group> q;
    q.push({{1},0});
    vis[1]=true;
    while(!q.empty()){
        Group cur=move(q.front());
        q.pop();
        vector<int> bucket[10];
        for(int u:cur.ver){
            for(const pair<int,int>& e:g[u]){
                int v=e.first,c=e.second;
                if(!vis[v])
                    bucket[c].push_back(v);
            }
        }
        for(int c=1;c<=9;c++){
            vector<int> nxt;
            int val=(1LL*cur.val*10+c)%P;
            for(int v:bucket[c]){
                if(vis[v])continue;
                vis[v]=true;
                ans[v]=val;
                nxt.push_back(v);
            }
            if(!nxt.empty())
                q.push({move(nxt),val});
        }
    }


    for(int i=2;i<=n;i++)
        cout<<ans[i]<<"\n";
    return 0;
}
