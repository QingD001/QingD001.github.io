标准库中的字符串

对于 string 类型，我们有如下封装好的操作：

  • a+b：将 b 拼接到 a 的末尾

  • s[i]：读取 s 的第 i 位

  • s.size()/s.length()：返回 s 的长度

  • s.find(ch,st)：从左到右查找并返回从 st 开始的字符 ch 的位置

  • s.rfind(ch)：从右到左查早并返回第一个找到的字符 ch 的位置

  • s.substr(st,len)：从 s 的 st 开始截取一个长度为 len 的字符串

  • s.append(j)：将 j 添加到 s 末尾

  • s.append(j,pos,n)：将字符串 j 的子串 j[pos...pos+n-1] 添加到 s 末尾

  • s.replace(pos,n,j)：删除从 pos 开始的 n 个字符，然后在 pos 处插入新串 j

  • s.erase(pos,n)：删除从 pos 开始的 n 个字符

  • s.insert(pos,j)：直接在 pos 位置插入字符串 j

对 char * 类型，同样有封装好的操作。但我觉得 string 更常用啊，这个就不记了。

字符串 Hash

字符串能否映射到整数域呢？这样的映射 f 被称为 Hash 函数。具体来说它有两个性质：

  • f(S)≠f(T)⇒S≠T

  • f(S)=f(T)⇒P(S=T)是一个接近 1 的较大值

对于 f(S)=f(T) 但 S≠T 的现象，被称为 Hash 碰撞。

多项式 Hash

多项式 Hash 把字符串看作是一个 P(P∈N∗) 进制数。具体地，对字符串 S 定义：

f(S)=∑i=1lSi×Pl−i(modM)

其中 Si 是某种字符对应整数的编码规则，可用 ASCII 码也可以自定义。而 M 是一个较大质数，譬如 109+7；或干脆定义 f 为 unsigned long long 类型，自然溢出无需再操作取模。常用 P=131 或 13331。

不妨定义 hi 表示 s[1..i] 的 Hash 值，则有递推关系：

hi=hi−1×P+si

且子串 s[l..r] 的 Hash 值就是：

H(l,r)=hr−hl−1×Pr−l+1

 

xxxxxxxxxx
typedef unsigned long long ull;
const int N=1e6+5;
const ull P=131;
ull h[N],p[N];
void init(string s){
    int n=s.size();
    s=" "+s;
    p[0]=1;
    for(int i=1;i<=n;i++){
        h[i]=h[i-1]*P+(ull)s[i];
        p[i]=p[i-1]*P;
    }
}
ull query(int l,int r){
    return h[r]-h[l-1]*p[r-l+1];
}

那么如果不考虑 Hash 碰撞，在模式匹配时我们只需要：

Hash 碰撞的概率分析

设 Hash 的取值空间元素数为 d，要计算的字符串数量为 n，则 Hash 碰撞概率为：

p(n,d)=1−p¯(n,d)=1−∏i=0n−1(1−id)

考虑到 d 之于 n 很大，采用近似 ex∼1+x，得到：

p(n,d)∼1−exp⁡(n(n−1)2d)

所以我们发现，当 n→d 时，碰撞概率就已经挺大的了。

Hack Hash

Hack Hash 研究的就是对于给出的 f ，如何构造两个不同的字符串 A,B 使 f(A)=f(B)

根据 f 的定义式，只要找到一组整数 d1,d2,…,dl 满足：

∑i=1ldiPl−i≡0modM

大模数 Hack Hash

根据前面的概率计算，若对 P=131,M=109+7，有 n=105 时 p(n,d)∼99.33%，也就是说随即构造 105 个字符串就有很大概率找到一组碰撞了。

x
typedef long long ll;
const ll P=131,M=1e9+7;
ll gethash(string s){
    ll res=0;
    for(int i=0;i<(int)s.size();i++){
        res=(res*P+(int)s[i])%M;
    }
    return res;
}
int main(){
    mt19937 rng(114514);
    unordered_map<ll,string> mp;
    for(int i=1;i<=200000;i++){
        string s="";
        for(int j=0;j<12;j++){
            s+=char('a'+rng()%26);
        }
        ll h=gethash(s);
        if(mp.count(h) && mp[h]!=s){
            cout<<mp[h]<<"\n"<<s<<"\n"<<h<<"\n";
            break;
        }
        mp[h]=s;
    }
}

数论性质 Hack Hash

还有一种针对特殊性质考量的方法，我们只考虑两个不同位置 i,j(i<j)，则碰撞条件即为：

diPl−i+djPl−j≡0modM

对于 gcd(P,M)=1 时，等价于：

diPj−i+dj≡0modM

不妨令 di=1,dj=−1 ，那么只需要找到 k 使 Pk≡1modM 后，任取 i 和 j=i+k 即可。

Ull Hack Hash

对于 M=264 ，也就是 unsigned long long 自然溢出时，有一种专门攻击的方法。

若 P 为偶数，注意到对 l≥64 时必然有 si×bl≡0modM 了，只要构造形如 aaaaa... 与 baaaa... 且长度大于 64 的字符串就能卡过去。

若 P 为奇数，我们定义 0/1 串 s 和 !s，其中 !s 是将 s 中所有 0 变为 1，1 变为 0 得到的。然后定义递推：

si+1=si+!si

譬如对于 s0=0，有 s1=01,s2=0110,s4=01101001…

设 hi=f(si),h¯i=f(!si),di=hi−h¯i 只要证明 264|di 即可。根据 s 递推的性质：

si=si−1+!si−1,!si=!si−1+si−1,|si|=2i−1

得到：

hi=hi−1P2i−2+h¯i−1  ,  h¯i=h¯i−1P2i−2+hi−1

从而：

di=di−1(P2i−2−1)

进而：

di=d1∏j=0i−2(P2j−1)

由于 P 是一个奇数，说明 P−1=0(mod2)，又：

P2k−1=(P2k−1−1)(P2k−1+1)

每进行一次平方，d 就多出至少一个因子 2，则至少十二次迭代得到的 d12 必然满足 266|d12 。因此我们搞出一个长度为 12 的这样的 s 即可定点爆破这种 hash 方式。

x
typedef unsigned long long ull;
ull gethash(const string &s,ull b){
    ull h=0;
    for(char c:s)
        h=h*b+(ull)c;
    return h;
}
int main(){
    string s="a";
    for(int i=2;i<=12;i++){
        string t=s;
        for(int j=0;j<(int)t.size();j++){
            if(t[j]=='a')t[j]='b';
            else t[j]='a';
        }
        s+=t;
    }
    string t=s;
    for(int i=0;i<(int)t.size();i++){
        if(t[i]=='a')t[i]='b';
        else t[i]='a';
    }
    ull b=131;
    cout<<s.size()<<"\n"<<gethash(s,b)<<"\n"<<gethash(t,b)<<"\n";
    cout<<(gethash(s,b)==gethash(t,b))<<"\n";
}

Hash 的改进与其它应用

双值 Hash

单个值容易被卡，那就用种模法。这样两个概率再一乘总会低点。

xxxxxxxxxx
using ull=unsigned long long;
ull base=131,mod[2]={212370440130137957,1e9+7};
ull get_hash(std::string s,int j){
   int len=s.size();
   ull ans=0;
   for(int i=0;i<len;i++)ans=(ans*base+(ull)s[i])%mod[j];
   return ans;
}
bool cmp(const std::string s, const std::string t) {
   bool f1=get_hash(s,0) != get_hash(t,0);
   bool f2=get_hash(s,1) != get_hash(t,1);
   return f1 || f2;
}

最长回文子串

给定长度为 n 的字符串，求它的最长回文子串的长度。

朴素想法是：二分答案长度 len，check函数内部依次枚举回文中心，用 Hash 判断两边是否相等。时间复杂度 O(nlog⁡n)

进一步思考，设 Ri:= 以 i 结尾的最长回文的长度。考虑到关键性质：

Ri≤Ri−1+2

因此寻找 Ri 时只需要暴力从 Ri−1+2 开始递减，直到找到第一个回文串。记变量 z 表示当前枚举的 Ri，初始时为 0，则每次 z 在 i 增大时初值都会增大 2，每次暴力循环都会减少 1。故暴力循环至多发生 2n 次，总时间复杂度 O(n)。

x
typedef unsigned long long ull;
const ull P=131;
struct Hash{
    int n;
    vector<ull> h,pw;
    Hash(string s):n(s.size()),h(n+1),pw(n+1){
        pw[0]=1;
        for(int i=0;i<n;i++){
            h[i+1]=h[i]*P+(ull)s[i];
            pw[i+1]=pw[i]*P;
        }
    }
    ull get(int l,int r){
        return h[r]-h[l]*pw[r-l];
    }
    bool isPal(int l,int r,Hash &rev){
        return get(l,r)==rev.get(n-r,n-l);
    }
};
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin>>s;
    string t=s;reverse(t.begin(),t.end());
    int n=s.size();
    Hash hs(s),ht(t);
    int z=0,ans=0;
    for(int i=0;i<n;i++){
        z+=2;
        while(z>i+1 || !hs.isPal(i-z+1,i+1,ht))--z;
        ans=max(ans,z);
    }
    cout<<ans<<"\n";
    return 0;
}

Manacher 算法在处理本问题时通常更标准。不过，Hash 也展示出了利用状态的单调性进行摊还分析的计算美学。

最长公共子串

给定 m 个总长不超过 n 的非空字符串，查找所有字符串的最长公共子串，其中 m,n≤106

很显然，如果存在长度为 k 的公共子串，必然存在长度为 k−1 的公共子串。因此直接二分最长公共子串的长度 len，check(len) 需要实现的就是将所有字符串长度为 len 的子串分别进行 Hash 后放入 Hash Table，并求交集。时间复杂度 O(m+nlog⁡n)。

x
#include<bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const ull P=131;
const int N=1e6+10;
int m;vector<string> s;
vector<ull> h[N],pw;
ull gethash(int id,int l,int r){
    return h[id][r]-h[id][l-1]*pw[r-l+1];
}
bool check(int len){
    unordered_map<ull,int> hh;
    hh.reserve(N*2);
    for(int i=1;i<=m;i++){
        unordered_set<ull> cur;
        int n=s[i].size()-1;
        for(int j=1;j+len-1<=n;j++)
            cur.insert(gethash(i,j,j+len-1));
        for(ull x:cur)
            if(++hh[x]==m)return 1;
    }
    return 0;
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>m;
    s.resize(m+1);
    int mnlen=1e6;
    for(int i=1;i<=m;i++){
        cin>>s[i];
        mnlen=min(mnlen,(int)s[i].size());
        s[i]=" "+s[i];
    }
    pw.resize(mnlen+1);
    pw[0]=1;
    for(int i=1;i<=mnlen;i++)
        pw[i]=pw[i-1]*P;
    for(int i=1;i<=m;i++){
        int n=s[i].size()-1;
        h[i].resize(n+1);
        for(int j=1;j<=n;j++)
            h[i][j]=h[i][j-1]*P+(unsigned char)s[i][j];
    }
    int l=0,r=mnlen;
    while(l<r){
        int mid=(l+r+1)>>1;
        if(check(mid))l=mid;
        else r=mid-1;
    }
    cout<<l<<"\n";
    return 0;
}

注意要预处理 h 数组，不然每次都 hash 的话会炸时间。

允许 k 个字符失配的模式匹配

给定源串 s 和模式串 p，求 s 中和 p 长度相同且不超 k 个字符失配的子串数量。

和暴力比起来，核心的优化点在于：每次跳过一整段匹配的字符。假设当前枚举源串中起点为 i 的子串 s[i...i+m-1]，其中 m=p.size()；我们希望知道它和 p 有多少个失配的位置。

字符串 Hash 能让我们快速判断两个子串是否相同。注意到，如果第 j 位已经不同了，那么之后肯定不同，所以二分查找第一个不同字符是可行的。找到第一个失配位置 j 后，直接跳过前面所有字符，即再类似的二分查找 s[j+1...i+m-1] 和 p 的第一个失配位置。重复该过程，直到 s 的这个子串燃尽了。此时校验查找到的失配字符数量即可。

x
#include<bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const ull P=131;
struct Hash{
    string s;
    vector<ull> h,pw;
    Hash(string s):s(s),h(s.size()+1),pw(s.size()+1){
        pw[0]=1;
        for(int i=0;i<(int)s.size();i++){
            h[i+1]=h[i]*P+(ull)s[i];
            pw[i+1]=pw[i]*P;
        }
    }
    ull get(int l,int r){
        return h[r]-h[l]*pw[r-l];
    }
    int lcp(Hash &b,int x,int y,int len){
        int l=0,r=len+1;
        while(l<r-1){
            int mid=l+r>>1;
            if(get(x,x+mid)==b.get(y,y+mid))
                l=mid;
            else
                r=mid;
        }
        return l;
    }
};
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string s,p;
    int k;
    cin>>s>>p>>k;
    int n=s.size(),m=p.size();
    if(m>n){
        cout<<0<<"\n";
        return 0;
    }


    Hash hs(s),hp(p);
    int ans=0;
    for(int i=0;i+m<=n;i++){
        int pos=0,cnt=0;
        while(pos<m && cnt<=k){
            int len=hs.lcp(hp,i+pos,pos,m-pos);
            if(pos+len==m)break;
            cnt++;
            pos+=len+1;
        }
        if(cnt<=k)ans++;
    }
    cout<<ans<<"\n";
    return 0;
}

KMP 自动机

前缀函数

对长为 n 的字符串 S，其前缀函数定义为一个长度为 n 的数组 π。π[i] 满足：

  • 若子串 S[0...i] 中有一对相等的真前缀与真后缀 s[0..k]=s[i-k+1..i]，则 π[i]=k

  • 如果不止一对，则取最长的那一对的长度为 π[i] 的值

  • 如果没有，则 π[i]=0

朴素计算前缀函数的方法如下，时间复杂度 O(n3)：

x
vector<int> calc(string s){
    int n=(int)s.length();
    vector<int> pi(n);
    for(int i=1;i<n;i++)
        for(int j=i;j>=0;--j)
            if(s.substr(0,j)==s.substr(i-j+1,j)){
                pi[i]=j;
                break;
            }
    return pi;
}

还是重复统计了很多信息，根据 2.4.2 的启发，我们发现：

π[i+1]≤π[i]+1

等号取得当且仅当 s[i+1]=s[π[i]]。（注意，这里的 S 是 0-based 的）

所以完全可以将 j 枚举的起点更换为 j=pi[i-1]+1，这样时间复杂度降为 O(n2)

不过这没有发掘出这个条件的潜力。我们沿着这个思路深入探索下：对于 s[i+1]≠s[π[i]] 时如何快速跳转呢？我们按照从大到小的顺序探索满足 s[0..k]=s[i-k+1..i] 的所有 k 值，找到第一个 s[k]=s[i+1] 即有 π[i+1]=k。

读者可能好奇，这些 k 值我们现在有统计吗？有的。不妨设这样的 k 值按照从大到小的顺序构成 k0(=π[i]),k1,k2,…,0 这个数列， 显然有：

s[0…kj]∈s[0…kj−1],∀j≥1

又根据前缀函数的最大性，得到：

kj+1=π[kj−1]

因此完全可以 O(n) 地转移：

x
vector<int> calc(string s){
    int n=(int)s.length();
    vector<int> pi(n);
    for(int i=1;i<n;i++){
        int j=pi[i-1];
        while(j>0 && s[i]!=s[j])j=pi[j-1];
        if(s[i]==s[j])++j;
        pi[i]=j;
    }
    return pi;
}

由于位置 i 的信息的更新不依赖于 i 之后的，所以这是一个在线算法。完全可以每读取一个字符就立刻计算出到这一位的前缀函数值。同时，这些 k 值也被我们称为 s 的 border。

有些教材也把前缀函数称为失配函数，这是针对它在 KMP 算法中的应用而言了。其实我觉得不太妥，毕竟它在其它字符串的领域也有广泛应用，前缀函数应该是更好的描述。

KMP 算法

介绍字符串 Hash 的时候，2.4.4 提到了一个特殊的模式匹配问题，而 kmp 是解决标准模式匹配问题的经典算法。问题描述：

给定一个源串 S 和模式串 p，找到所有 p 在 S 中出现的位置。

设 n=S.size(),m=p.size()，构造一个字符串 J=p+'#'+S，其中 # 可以是一个任意非公共字符（分割记号）。对字符串 J 而言，其前缀函数的第 m+1 到 n+m 位（0-based）的意义值得思考。根据定义，π[i] 表示右端点为 i 且同时为一个前缀的最长真子串的长度；由于分隔符的存在，这个长度不可能超过 m 。所以，如果有 m+1≤i≤n+m,π[i]=m 成立，说明 p 完整出现在了源串 S 的第 i−(m−1)−(m+1)=i−2m 处。

说实话挺妙的，代码实现如下：

x
vector<int> kmp(string s,string p){
    int n=s.size(),m=p.size();
    string wzc=p+'#'+s;
    vector<int> pi=calc(wzc),ans;
    for(int i=m+1;i<=n+m;i++)
        if(pi[i]==m)ans.push_back(i-2*m);
    return ans;
}

时间复杂度为 O(n+m) 。

前缀函数与 KMP 思想的其它用法

统计每个前缀的出现次数

给定一个长度为 n 的字符串 S，本部分我们将研究两个问题：

  • Ques1：统计每个前缀 s[0...i] 在同一个字符串的出现次数

  • Ques2：统计每个前缀 s[0...i] 在另一个给定字符串 T 中的出现次数

Ques1

考虑位置 i 的前缀函数值 π[i]。根据定义，我们知道字符串 s 的一个长为 π[i] 的前缀在位置 i 出现且以 i 为右端点；且更短的一些前缀也可能以 i 为右端点。所以我们又遇到了关于 border 的问题。不断寻找更小的 border，直到找到 0 为止。这个过程中进行统计即可。

x
void calc(string s){
    int n=s.size();
    vector<int> pi=calc(s),ans(n+1);
    for(int i=0;i<n;i++)++ans[pi[i]];
    for(int i=n-1;i>0;i--)ans[pi[i-1]]+=ans[i];
    for(int i=0;i<=n;i++)ans[i]++;
}

如果我们知道 s 的长度为 i 的前缀出现了恰好 ans[i] 次，那么该值必须被叠加至其最长的既是后缀也是前缀的子串的出现次数中。最后，为了统计原始的前缀，我们对每个结果加 1

Ques2

运用在 KMP 算法中学到的技巧，同样的构造 J 且只统计 i≥m+1 的 π[i] 值。之后的流程就类似 Ques1 。

void calc(string s,string t){
    string wzc=t+'#'+s;
    int n=s.size();
    vector<int> pi=calc(wzc),ans(n+1);
    for(int i=n+1;i<(int)wzc.size();i++)
        ans[pi[i]]++;
    for(int i=n;i>0;i--)
        ans[pi[i-1]]+=ans[i];
    for(int i=0;i<=n;i++)
        ans[i]++;
}

统计本质不同子串的数目

给定一个长度为 n 的字符串 s，求其本质不同子串的数量。

假设当前字符串 cur 的长度为 n，已经统计好了本质不同子串数。现在在末尾添加字符 c。

由于只有以新字符 c 结尾的子串可能是新出现的，这样的子串一共 n+1 个。

令 t=s+c，将其首尾反转得到 t¯，计算 t¯ 的前缀函数后，记：

mx=maxiπ[i]

即 mx 表示 t^ 的最长的“前缀在自身其他位置出现的长度”。反转回来，就等于 t 的最长的“后缀曾经出现的最长长度”。因此，长度不超过 mx 的后缀都已经出现过了；而长度大于 mx 的后缀必然没出现过。则新增的本质不同子串数量为：

|t|−mx=|s|+1−mx

因此，每次添加字符后重新计算前缀函数。总复杂度 O(n2)

x
int distinct_substrings(string s){
    string t;
    int ans=0;
    for(char c:s){
        t+=c;
        string rev=t;
        reverse(rev.begin(),rev.end());
        vector<int> pi=calc(rev);
        int mx=*max_element(pi.begin(),pi.end());
        ans+=(int)t.size()-mx;
    }
    return ans;
}

字符串压缩

给定一个长度为 n 的字符串 s，希望找到一个最短字符串 t 使 s 可以表示为 t 的一份或多份复制的拼接表示。即 s=tt…t 。

这样的 t 的长度 k 必然是 s 的一个周期，而周期意味着去掉前 k 个字符剩下的部分和去掉后 k 个字符后的剩下的部分相同。更有趣的是，对于可以表示成 s=tt…t 的字符串 s，必然有一段很长的公共前后缀；而这个前后缀的重叠部分，就可以作为备选。

具体而言，我们取备选值：

k=n−π[n−1]

下面证明，若 k|n，必然有 |t|=k；反之 |t|=n。

考虑反证法。对 k|n，若存在一个比 k 更小的压缩表示，则必有 π[n−1]>n−k，矛盾。

对 k|̸n，假设存在最小压缩表示 r 的长度为 p(p|n)，字符串被划分为 n/p≥2 块。显然有：

π[n−1]>n−p

同时，由于 k 是周期，显然有：

r(i+k)modp=rimodp

根据数论知识得到，压缩表示 r 本身也具有 gcd(k,p) 这个周期。由于 gcd(k,p)≤k<p，那么它可以完整地重复拼接成 r，这和 p 的最小性矛盾。根本不存在这样的 r！

xxxxxxxxxx
string compress(string s){
    int n=s.size();
    vector<int> pi=calc(s);
    int k=n-pi[n-1];
    if(n%k==0)return s.substr(0,k);
    return s;
}

KMP 自动机

普通 KMP 算法在速率层面已经相当优秀，不过对于大量转移或在某个 dp 过程中需要知晓：

当前已经匹配了 j 个字符，接下来放入字符 c，状态会怎么变化？

这就需要 KMP 自动机了。我们前面说过，前缀函数的计算是一个在线算法，因此可以构造一个自动机：其状态为当前的前缀函数值，从一个状态到另一个状态的转移则由新读入的字符确定。朴素地：

x
void autokmp(string s,vector<vector<int>> & aut){
    s+='#';
    int n=s.size();
    vector<int> pi=calc(s);
    aut.assign(n,vector<int>(26));//只考虑小写字母
    for(int i=0;i<n;i++){
        for(int c=0;c<26;++c){
            int j=i;
            while(j>0 && 'a'+c!=s[j])j=pi[j-1];
            if('a'+c==s[j])++j;
            aut[i][c]=j;
        }
    }
}

然而这样的时间复杂度是 O(|∑|n2)。不过，很显然不必要单独的每次重复类似 kmp 的过程，而是可以运用已经计算过的 aut[i][c]。只要从值 j 变化为 π[j−1]，实际上就是在说转移 (j,c) 所到达的状态和 (π[j−1],c) 一样，但这个一定在之前计算过了。

x
void autokmp(string s,vector<vector<int>> & aut){
    s+='#';
    int n=s.size();
    vector<int> pi=calc(s);
    aut.assign(n,vector<int>(26));//只考虑小写字母
    for(int i=0;i<n;i++){
        for(int c=0;c<26;++c){
            if(i>0 && 'a'+c!=s[i])
                aut[i][c]=aut[pi[i-1]][c];
            else
                aut[i][c]=i+('a'+c==s[i]);
        }
    }
}

这样，时间复杂度来到了 O(|∑|n)，其中 |∑| 是字符集的大小。
