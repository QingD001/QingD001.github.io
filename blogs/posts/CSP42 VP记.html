A - 银行家舍入

小 P 的实验表格里有 n 个形如 xxx.x 的、保留一位小数的非负实数，其中：

  • 小数点前的 xxx 表示整数部分 a，为任意非负整数；

  • 小数点后的 x 表示小数部分 b*，为一位数字，取值 0-9；

  • a 可以是任意位数（如 2026、531 或 0）；b* 必为一位，且当 b*=0 时不会省略（如 13.0）。

为方便统计分析，小 P 想将它们都近似为整数，具体定义两种计算方式。

  1. 四舍五入法

  • 当 0≤b≤4 时，向下舍去，结果为 a*；

  • 当 5≤b≤9 时，向上进位，结果为 a+1。

  1. 银行家舍入法（向偶数舍入）

  • 当 b≠5 时，处理与四舍五入法一致。

  • 当 b=5 时，由于 a*+0.5 与相邻整数 a 和 a+1 的距离相同，为避免系统性偏差，向偶数舍入：若 a 为偶数，则结果为 a；否则结果为 a+1。

现给出小 P 表格中的 n 个实数（格式如上）。对每个实数，分别计算上述两种方法的取整结果。

神秘模拟题，题目说了要用 string。

#include<bits/stdc++.h>

typedef long double ld;
int calc(string s){
    int res=0,p=1,i=1;
    while(i<s.size()-2)p*=10,++i;
    for(i=0;i<s.size()-2;++i)
        res+=(s[i]-'0')*p,p/=10;
    return res;
}
int main(){
    int n;
    cin>>n;
    vector<string>a(n);
    for(int i=0;i<n;i++)cin>>a[i];
    for(int i=0;i<n;i++){
        int b=a[i].back()-'0';
        if(b<=4)cout<<calc(a[i])<<" ";
        else cout<<calc(a[i])+1<<" ";
    }
    cout<<"\n";
    for(int i=0;i<n;i++){
        int b=a[i].back()-'0';
        if(b!=5){
            if(b<=4)cout<<calc(a[i])<<" ";
            else cout<<calc(a[i])+1<<" ";
        }else{
            if(calc(a[i]) & 1)cout<<calc(a[i])+1<<" ";
            else cout<<calc(a[i])<<" ";
        }
    }
    return 0;
}

B - 机器人宿管指南

管理员小 P 会定期向机器人宿舍投放苹果。已知初始（第 0 天）有 n 个苹果。从第 1 天起，每天按如下流程进行：

  • 根据经验，每天约有 k% 的苹果会变质。若前一天剩余 t 个苹果，则可近似认为有 ⌈t⋅k/100⌉个会变坏（其中 ⌈⋯ ⌉ 表示向上取整）。

  • 丢弃所有坏苹果后，每个机器人会食用一个苹果。

显然，宿舍中如果入住过多机器人，每次投放的 n 个苹果可能很快就被吃光了。小 P 希望这些苹果至少够机器人们吃 m 天，试计算宿舍中最多可以入住多少机器人。

1≤n≤1018,1≤k≤5,1≤m≤2000

好像可以用数学的方法做，但二分不用动脑子。

#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
ll n;
int k,m;
ll upf(ll a,ll b){
    __int128 t=(__int128)a*b;
    ll res=(ll)(t/100+(t%100!=0));
    return res;
}
bool check(ll x){
    ll lft=n;
    for(int i=1;i<=m;i++){
        if(lft<0)return false;
        lft-=(upf(lft,k)+x);
    }
    return lft>=0;
}
int main(){
    cin>>n>>k>>m;
    ll l=0,r=n;
    while(l<r){
        ll mid=l+(r-l+1)/2;
        if(check(mid))l=mid;
        else r=mid-1;
    }
    cout<<l;
    return 0;
}

D - 石子游戏

小 C 和小 S 正在玩一种石子游戏，规则如下：

  • 有 m 个仓库，从左到右编号为 1,2,…,m，i 号仓库初始存有 ai 个石子。

  • 两位玩家轮流操作，小 S 先手。每轮操作可任选一个仓库 i，从中取出任意大于 0 数量的石子，将取出石子移至 i−1 号仓库。特别地，若 i=1，取出的石子将直接被丢弃。

  • 当全部仓库石子均被清空时游戏终止，此时无法进行操作的玩家判负。

聪明的小 C 发现他必胜的条件为：所有奇数编号仓库的石子数异或和为 0，即 a1⊕a3⊕⋯⊕a2k−1=0， m=2k−1 或 2k，其中 ⊕ 表示二进制异或操作。

给定 n 个仓库，从左到右编号为 1,2,…,n，i 号仓库初始存有 bi 个石子。

定义子游戏 (l,r)：选取仓库 l∼r 进行上述石子游戏，将其视作一组新仓库，i 号仓库初始石子数为 ai=bi+l−1。

共有 q 个互相独立的询问，每个询问给出区间 [L,R]。小 C 需要把 [L,R] 分割为若干个子区间 [l1,r1],[l2,r2],…,[lk,rk]，满足 l1=L,rk=R,ri=li+1−1 (1≤i<k)，使得在 k 个子游戏 (l1,r1),(l2,r2),…,(lk,rk) 中他必胜的子游戏数量尽可能地多。求所有合法分割方案里，小 C 必胜的子游戏数量的最大值。

我得了一种看到博弈论相关背景和 xor 就脑壳疼的病。好在这个题不用研究这个游戏本身的必胜条件，题目背景已经给出来了。

一个洞察是，子游戏里奇数编号的堆 ⇔ 原数组里和 l 同奇偶的位置。这很好理解，因为等于是平移了 l−1 位。为了快速判断一段区间的异或和是否为 0，自然考虑维护前缀异或和。

要切分出最多的必胜区间，这是区间调度问题。经典结论是按照右端点排序，能选就选/能切就切。直观地，右端点越小给后面留的空间当然就最大，或者说，给后续的“可选择性”最大。而且，这里的区间互不交，所以切出去一个并不会让整体更劣。

朴素的做会 O(nq)，而优化思路也很显然。重复维护的信息其实就是对每个询问的 [L,R] 都从 L 开始暴力找下一个必胜区间的起点，然而这玩意很显然只和起点有关，且可以用倍增的手段跳步。因此，我们维护 nxt[i] 表示从 i 开始最近的必胜区间右端点的后一位（即新区间开始位），正式一点：

nxt[i]:=1+arg⁡minXor[i…j]=0,j≥i⁡j=1+arg⁡minpre[i]=pre[j],j≥i⁡j

也就是这其实是一个寻找后缀第一个相同值的问题，这很二分。倍增数组 f(i,j) 表示从 j 出发沿着 nxt 链跳 2i 步到达的位置，最终倍增查表即可。

这里还有一个边界上的细节，因为 query 区间 [L,R] 不保证 L 就是一个必胜区间的起点；所以 nxt 如果仅按照现在的处理会遗漏这种情况。我们只需要对求解后的 nxt 取后缀最小值，它的意义就变成：

nxt[i]:=1+arg⁡minXor[k…j]=0,i≤k≤j⁡j

这个操作的正确性就基于取更小右端点更优的贪心论断。被跳过的 i 就肯定是某个不胜区间里的元素了，不影响结果。
