C. Bento Packing

Problem Statement

There are N side dishes.

The i-th side dish has a deliciousness of Ai and a volume of Bi.

You will choose some of the side dishes so that the total volume of the chosen dishes is at most W, and pack them into a lunch box.

Find the maximum possible total deliciousness of the chosen side dishes.

Constraints

  • 1≤N≤20

  • 1≤W≤109

  • 1≤Ai,Bi≤109

  • All input values are integers.

看到题目直接写了个背包，交了一发喜提 RE。看了眼数据范围才发现 W 巨大且 n 很小，直接爆搜 O(n2n) 就能过啊，连剪枝都不用加，气笑了。用二进制枚举，看着不烧心。

x
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
int main(){
    int n,v;
    cin>>n>>v;
    ll ans=0;
    vector<ll> a(n),b(n);
    for(int i=0;i<n;i++)cin>>a[i]>>b[i];
    for(int s=0;s<(1<<n);s++){
        ll ww=0,vv=0;
        for(int i=0;i<n;i++){
            if((s>>i) & 1)
                ww+=a[i],vv+=b[i];
            if(vv>v)break;
        }
        if(vv>v)continue;
        ans=max(ans,ww);
    }
    cout<<ans;
    return 0;
}

D. Back and Forth Distance

Problem Statement

There are N squares arranged in a row, numbered 1,2,…,N from left to right.

When you are on square i, you can make one of the following moves.

  • Choose an integer j such that 1≤j<i, and move to square j. The cost of this move is Li.

  • Choose an integer j such that i<j≤N, and move to square j. The cost of this move is Ri.

You are given Q queries. Answer each of them. Each query is in the following format.

  • Integers s and t are given. Find the minimum total cost required to reach square t from square s by repeatedly making moves.

Constraints

  • 2≤N≤3×105

  • 1≤Q≤3×105

  • 1≤Li≤109 (2≤i≤N)

  • 1≤Ri≤109 (1≤i≤N−1)

  • 1≤s,t≤N for each query.

  • s≠t for each query.

  • All input values are integers.

不难发现最多走两步。要么直接走，要么先绕后面再折返。对于折返的情况，维护下 r 的前缀最小值和 l 的后缀最小值就行了。

x
#include<bits/stdc++.h>
using namespace std;
constexpr int inf=1e9+1;
int main(){
    int n,q;
    cin>>n>>q;
    vector<int> l(n+1),r(n+1),rmp(n+1,inf),lms(n+1,inf);
    for(int i=2;i<=n;i++)
        cin>>l[i];
    for(int i=1;i<n;i++){
        cin>>r[i];
        rmp[i]=min(rmp[i-1],r[i]);
    }
    lms[n]=l[n];
    for(int i=n-1;i>=2;i--)lms[i]=min(lms[i+1],l[i]);
    while(q--){
        int s,t;
        cin>>s>>t;
        if(s<t)
            cout<<min(r[s],l[s]+rmp[s])<<"\n";
        else
            cout<<min(l[s],r[s]+lms[s])<<"\n";
    }
    return 0;
}

F. Narrow Passage

Problem Statement

There are N people standing on a number line. The people are numbered 1,2,…,N, and initially person i is at coordinate Si. Here, the Si are pairwise distinct.

You can repeatedly perform the following operation.

  • Choose one person. Let x be the coordinate where that person currently is, and move them to x−1 or x+1. If there is a person at the destination, that person is simultaneously moved to coordinate x.

Find the minimum number of operations required to reach a state where each person i is at coordinate Ti. Here, the Ti are pairwise distinct.

Constraints

  • 1≤N≤2×105

  • 0≤Si,Ti≤109

  • Si≠Sj and Ti≠Tj if i≠j.

  • All input values are integers.

两个人如果方向不同且相邻，一次操作即可满足两个人的需求。对于人挤人的情况（也就是 1≤Si≤Ti≤N 的情况），只要统计逆序对数量，即需要知道有多少在初始状态中排在前面的人在目标状态后排到了后面。

不过这里并不是中国，所以没这么挤。还需要计算人和空格交换的次数。运用前缀和的思想，我们维护第 i 个人起始位置和终止位置分别到起点的空格数量，相减即可得知此人至少和多少个空格进行交换。具体而言，设此人的初始位置在所有人初始位置的升序排名 pi，则其起始位置左侧空格的数量应该是 Si+1−pi；同理，其终止位置在所有终止位置排名 qi，则其终止位置左侧空格的数量应该是 Ti+1−qi。则空格差：

|(Si−pi)−(Ti−qi)|

所以答案分为两部分：1.所有人和空格交换的次数 2.所有逆序对的数量。逆序对是初始位置 i<j 且最终位置反之的，最终位置要怎么表达呢？初始位置（离散化后的）为 i 的人的编号维护为 ai；而 pi 是第 i 个人的初始排名，所以可以得知 a 和 p 互为逆映射。因此，最终位置应该是 qai。我们要在 {qa1,qa2,…,qan} 上找逆序对数。

x
#include<bits/stdc++.h>
using namespace std;
struct BIT{
    int n;
    vector<int> tr;
    BIT(int n):n(n),tr(n+1,0){}
    void add(int x){
        for(;x<=n;x+=x&-x)++tr[x];
    }
    int query(int x){
        int res=0;
        for(;x;x-=x&-x)res+=tr[x];
        return res;
    }
};
int main(){
    int n;
    cin>>n;
    typedef long long ll;
    vector<pair<ll,int>> s(n),t(n);
    vector<int> p(n+1),q(n+1);
    for(int i=0;i<n;i++){
        cin>>s[i].first;
        s[i].second=i+1;
    }
    for(int i=0;i<n;i++){
        cin>>t[i].first;
        t[i].second=i+1;
    }
    sort(s.begin(),s.end());
    sort(t.begin(),t.end());
    for(int i=0;i<n;i++)p[s[i].second]=i+1,q[t[i].second]=i+1; 
    ll ans=0;
    for(int i=0;i<n;i++){
        int id=s[i].second;
        ll x=s[i].first-p[id],y=t[q[id]-1].first-q[id];
        ans+=abs(x-y);
    }
    BIT tr(n);
    for(int i=0;i<n;i++){
        int x=q[s[i].second];
        ans+=i-tr.query(x);
        tr.add(x);
    }
    cout<<ans;
    return 0;
}
