F. Range Update Point Query

Given an array a1,a2,…,an, you need to handle a total of q updates and queries of two types:

  • 1 l r — for each index i with l≤i≤r, update the value of ai to the sum of the digits of ai.

  • 2 x — output ax.

Input

The first line of the input contains an integer t ( 1≤t≤1000) — the number of testcases.

The first line of each test case contains two integers n and q ( 1≤n,q≤2⋅105) — the size of the array and the number of queries, respectively.

The second line of each test case contains n integers a1,a2,…,an ( 1≤ai≤109).

The next q lines of each test case are of two forms:

  • 1 l r ( 1≤l≤r≤n) — it means, for each index i with l≤i≤r, you should update the value of ai to the sum of its digits.

  • 2 x ( 1≤x≤n) — it means you should output ax.

There is at least one query of the second type.

The sum of n over all test cases does not exceed 2⋅105.

The sum of q over all test cases does not exceed 2⋅105.

我们一定要记得数据结构减少时间复杂度的原理在于它避免了对“不需要访问”的空间的访问，而不要光记得某个数据结构的时间复杂度是多少。这个题，每次操作会让区间 [l,r] 的所有数字变成它们自身的数位和，我们注意到这个变化的速率是非常快的，就算最大的可能也只是 109−1→81→9 仅三步。这时候已经可以写一个不那么暴力的代码了：

#include<bits/stdc++.h>
using namespace std;
int calc(int x){
    int res=0;
    while(x){
        res+=x%10;
        x/=10;
    }return res;
}
void solve(){
    int n,q;
    cin>>n>>q;
    vector<int> a(n+1),v(n+1,0);
    for(int i=1;i<=n;i++)cin>>a[i];
    while(q--){
        int op;
        cin>>op;
        if(op==1){
            int l,r;
            cin>>l>>r;
            for(int j=l;j<=r;j++){
                if(v[j]>3)continue;
                a[j]=calc(a[j]);
                ++v[j];
            }
        }else{
            int x;
            cin>>x;
            cout<<a[x]<<"\n";
        }
    }
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }   
    return 0;
}

可惜还是没能卡过去。不过，既然变成个位数以后这个位置就不可能再变化了，成为了所谓“不需要访问”的空间的元素。我们现在还是很朴素的去遍历和用 vj 的方法来标记，怎么更快知道哪些是不需要访问的“空间”呢？我们做区间切分，对于一个小区间 [l,r] 如果 maxl≤i≤rai 都是个位数，说明这个区间已经全是个位数了，当然都不需要访问；反之就可能需要探索它的子区间再去比对。总之，用线段树维护区间最大值就行了。

xxxxxxxxxx
#include<bits/stdc++.h>
#define ls(x) x<<1
#define rs(x) x<<1|1
using namespace std;
const int N=2e5+10;
//由于数位不超过 9，其实应该维护区间最大值，而且随着更新最后一定是->个位数
//所以不超过9 的直接跳了
int calc(int x){
    int res=0;
    while(x){
        res+=x%10;
        x/=10;
    }return res;
}
int tr[N<<2|1],a[N];
void build(int x,int l,int r){
    if(l==r){
        tr[x]=a[l];
        return ;
    }
    int mid=l+r>>1;
    build(ls(x),l,mid);
    build(rs(x),mid+1,r);
    tr[x]=max(tr[ls(x)],tr[rs(x)]);
}
void modify(int x,int l,int r,int ql,int qr){
    if(tr[x]<=9)return ;
    if(l==r){
        tr[x]=calc(tr[x]);
        return ;
    }int mid=l+r>>1;
    if(ql<=mid)modify(ls(x),l,mid,ql,qr);
    if(qr>mid)modify(rs(x),mid+1,r,ql,qr);
    tr[x]=max(tr[ls(x)],tr[rs(x)]);
}
int query(int x,int l,int r,int p){
    if(l==r)return tr[x];
    int mid=l+r>>1;
    if(p<=mid)return query(ls(x),l,mid,p);
    else return query(rs(x),mid+1,r,p);
}
void solve(){
    int n,q;
    cin>>n>>q;
    for(int i=1;i<=n;i++)cin>>a[i];
    build(1,1,n);
    while(q--){
        int t;
        cin>>t;
        if(t==1){
            int l,r;
            cin>>l>>r;
            modify(1,1,n,l,r);
        }else{
            int x;
            cin>>x;
            cout<<query(1,1,n,x)<<"\n";
        }
        
    }
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    
    return 0;
}

E. It All Went Sideways

Yousef has n columns of cubes standing side by side. The i-th column contains ai identical unit cubes stacked vertically. Initially gravity pulls cubes downwards, so every column i contains exactly ai cubes at heights 1,2,…,ai.

Suddenly, gravity shifts to the right. Each cube slides horizontally as far to the right as possible. A cube cannot pass through or overlap other cubes, and it must remain at its original height. The final configuration is uniquely determined by the initial heights.

Before and after applying rightward gravity.

Before the gravity shift, Yousef may perform at most one operation: choose an index i and decrease ai by 1 (i.e. remove one cube from that column). He may also choose to do nothing.

A cube is said to move if its column index after the gravity shift is different from its original column index.

Find the maximum possible number of cubes that will move after the gravity shift, assuming Yousef applies the single decrease optimally (or chooses not to apply it).

重力向右，考虑第 i 列高度为 ai=h 的方块；如果右侧存在某一列高度小于 h，那么这个方块肯定移动；如果从第 i→n 列所有方块的高度都至少为 h，说明它不移动。因此维护后缀最小值 si 是很自然的想法。不执行任何操作时， sum=∑i=1n(ai−si) 为全部移动的总量。

那么删除某个列的一个方块为何能增加方块移动的数量呢？因为删除它就会导致原来的很多个 si 减少，当然就有 sum 增加了！下面考虑怎么删。由于顶多删一个，所以移动方块的增量一定只是 1×δL，要让 δL 最大，显然是去找最长连续段了！

xxxxxxxxxx
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
void solve(){
    int n;
    cin>>n;
    vector<ll> a(n+1);
    ll sum=0;
    for(int i=1;i<=n;i++){
        cin>>a[i];
        sum+=a[i];
    }
    vector<ll> s(n+1);
    s[n]=a[n];
    sum-=s[n];
    for(int i=n-1;i;i--){
        s[i]=min(s[i+1],a[i]);
        sum-=s[i];
    }
    ll mx=-1,cur=1;
    for(int i=2;i<=n;i++){
        if(s[i]==s[i-1])++cur;
        else mx=max(mx,cur),cur=1;
    }
    mx=max(mx,cur);
    cout<<sum+mx-1<<"\n";
    return ;
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
