E: Square Jam

Grammy is a puzzle master. Today, she is playing a variant of "Square Jam" puzzle. Given an n×m rectangle. The goal is to divide the rectangle into several squares (with integral lengths) such that no point is touched by 4 squares.

The left picture illustrates a solution to a 4×6 puzzle, and the right picture shows an example of what is not allowed in the solution.

Grammy surely knows how to solve the puzzle, but she decided to give you a quiz. Please solve the puzzle.

这个很容易想到每次都尽量取最大的正方形然后递归下去啊，且容易证明由于允许存在 1*1 的小方格，一定有合法构造方案；而且这样每次取最大正方形，x、y 坐标都递增的情况下，显然不存在十字交叉的点。比较坑的点就是这种 n 行 m 列的方格要搞清楚哪个是横坐标哪个是纵坐标……之前 csp 就吃过这个亏。复杂度挺低的，因为这等于是一个辗转相除法。

#include<bits/stdc++.h>
using namespace std;
void solve(){
    int n,m;
    cin>>n>>m;
    vector<tuple<int,int,int>> res;
    int h=n,w=m,x=0,y=0;
    while(w>0&&h>0){
        if(w>h){
            int q=w/h;
            for(int i=0;i<q;i++)
                res.emplace_back(x,y+i*h,h);
            y+=q*h;
            w%=h;
        }
        else if(w<h){
            int q=h/w;
            for(int i=0;i<q;i++)
                res.emplace_back(x+i*w,y,w);
            x+=q*w;
            h%=w;
        }
        else{
            res.emplace_back(x,y,w);
            break;
        }
    }
    cout<<"YES\n";
    cout<<res.size()<<"\n";
    for(auto &[x,y,l]:res)
        cout<<x<<" "<<y<<" "<<l<<"\n";
}


int main(){
    int T;
    cin>>T;
    while(T--){
        solve();
    }
    return 0;
}

G:Game

Alice and Bob are playing a game.

There are n numbers on the black board, where the i-th number is ai. Alice and Bob play in turns. Alice plays first. The current player can choose two numbers ai and aj from the black board (i and j can be equal), and write a new number ai⊕aj on the blackboard, where ⊕ denotes bitwise-xor operation. The players cannot skip their turns. The player who writes number k on the blackboard wins.

If no one writes k on the blackboard in 10100 rounds, then the game ends in a draw.

Now, assume Alice and Bob both play optimally, determine the outcome of the game (Alice wins, Bob wins, or draw).

这里有一个性质，就是数字只会增多不会减少。二者都是理性人，为了不让对方获胜，应确保当前步构造完毕后必然不存在

x,y∈S∧x⊕y=k

我们称这个条件为 W(S)。首先看初始的数字集合 S，如果有 W(S)，则 Alice 直接赢了；接下来我们在 not W(S) 的前提下讨论。由于构造出新数会产生不确定性，所以如果当前不是必赢的局面且存在可以“打太极”的空间，二者必然倾向于选择“打太极”的方式。这就是最优策略。

注意到对于 x⊕y=z，有 x⊕z=y。甚至 Alice 可以直接 x⊕x=0 之后二人都一直 x⊕0=x，保持一种循环直到平局。这就是一种打太极，所以对于 k∉S 的情况，就显然直接开始这样循环了，输出 Draw 即可。

比较有意思的情况是 k∈S0 。Alice 必须寻找所谓的安全步，也即寻找 (x,y)∈S×S 使得：

x⊕y⊕k∉S

如果存在，那么走完这一手之后二人都可以无限开始打太极；如果不存在，那么无论 Alice 怎么走都必然是 Bob 获胜。这就是我们的核心观察。

再利用一个保持不变性，我们设：

T={x⊕k|x∈S}

则只需判定是否：

∀u,v∈T,u⊕v∈T

即 T 是否是 F2 上的线性子空间。那么搞一个线性基的模板就行了。

#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
struct Basis{
    static const int B=61;
    ll p[B];
    int rk;
    Basis(){
        memset(p,0,sizeof(p));
        rk=0;
    }
    void insert(ll x){
        for(int i=B-1;i>=0;i--){
            if(((x>>i)&1)==0)continue;
            if(!p[i]){
                p[i]=x;
                rk++;
                return;
            }
            x^=p[i];
        }
    }
};


void solve(){
    int n;
    ll k;
    cin>>n>>k;
    vector<ll>a(n);
    unordered_set<ll>s;
    for(int i=0;i<n;i++){
        cin>>a[i];
        s.insert(a[i]);
    }
    for(ll x:s){
        if(s.count(x^k)){
            cout<<"Alice\n";
            return;
        }
    }
    // k 不在黑板上，Alice 制造 0，然后永久拖延
    if(!s.count(k)){
        cout<<"Draw\n";
        return;
    }
    // 构造 T = {x xor k}
    Basis bs;
    for(ll x:s)bs.insert(x^k);
    int m=s.size();
    bool full=false;
    if(bs.rk<63)full=((1ULL<<bs.rk)==(unsigned long long)m);
    if(full)cout<<"Bob\n";
    else cout<<"Draw\n";
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }


    return 0;
}

D:Error Permutation

You are given a permutation P of length n. Find the number of its subsegments [l…r]( l≤r) that satisfies the following condition:

  • ∀1≤i≤r−l+1 , the i-th element of this subsegment (that is, Pl+i−1) is not the i-th smallest element in this subsegment.

题面挺朴素的，就是统计所有 P 的子段中满足第 i 位数都不是第 i 小的子段的数量。具体来说，比如现在固定了一个子段 pl→pr 和某个位置 j，给出论断：

如果 j 是一个 invalid 位置，必然左边比 pj 大的数量等于右边比 pj 小的数量。

（这个 trick 我怎么记得在别的题见过呢……）这下就很容易统计了，我们固定 l 和 j，由于右边的“比 pj 小”的个数随着 r 的增大只会呈现平台不减的数列形态如 0,0,1,1,1,2,2… 之类。所以对于固定的 (l,j)，满足条件的 r 必然构成一个整数域上连续的区间。

具体的，我们预处理出 small[j] 记录每个下标 j 右侧所有比 pj 小的数对应的下标，显然按照正常的顺序枚举就能确保每个 small[j]都是有序的。接着倒序枚举 l，定义 cnt[l] 表示 [l,j−1] 中比 pj 大的数的个数。

#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
void solve(){
    int n;
    cin>>n;
    vector<int> p(n+1);
    for(int i=1;i<=n;i++)cin>>p[i];
    // small[j]：j右边所有 < p[j] 的位置
    vector<vector<int>> small(n+1);
    for(int j=1;j<=n;j++)
        for(int i=j+1;i<=n;i++)
            if(p[i]<p[j])
                small[j].push_back(i);
    // cnt[j] = [l,j-1] 中 > p[j] 的数量
    vector<int> cnt(n+1,0);
    ll ans=0;
    for(int l=n;l>=1;l--){
        cnt[l]=0;
        for(int j=l+1;j<=n;j++)
            if(p[l]>p[j])
                cnt[j]++;
        vector<int> diff(n+2,0);//diff[r]表示r被某个坏区间覆盖的次数的差分序列
        for(int j=l;j<=n;j++){
            int k=cnt[j],sz=small[j].size();
            if(k>sz)continue;
            int L,R;//对 (l,j) 不合法的 R 的区间
            if(k==0)L=j;
            else L=small[j][k-1];
            if(k==sz)R=n;
            else R=small[j][k]-1;
            diff[L]++;
            diff[R+1]--;
        }
        int cover=0;
        for(int r=l;r<=n;r++){
            cover+=diff[r];
            if(cover==0)ans++;
        }
    }
    cout<<ans<<"\n";
}


int main(){
    int t;
    cin>>t;
    while(t--)
        solve();
    return 0;
}
